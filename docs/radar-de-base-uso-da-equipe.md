# Radar de Base: Guia de Uso para a Equipe de Mobilização

Este guia explica como utilizar o Radar de Base na rotina diária para transformar interações digitais em mobilização real usando o **Radar Design System (UX10)**.

## 1. Filosofia Operacional

O Radar de Base **não é um sistema de spam**. 
- **Foco Humano**: Cada contato deve ser manual e contextualizado.
- **Vínculo, não Voto**: Na pré-campanha, o objetivo é ouvir, criar vínculo e convidar para a construção coletiva. Nunca peça voto.
- **Manual Sempre**: Não existem disparos automáticos. Você abre o Instagram e manda a mensagem.

## 2. Rotina Diária (O Ciclo de 5 Minutos)

1.  **Abra a "Rotina do Dia"**: Acesse `/pessoas`.
2.  **Veja os 10 Prioritários**: O sistema seleciona quem interagiu mais ou trouxe relatos importantes.
3.  **Entenda o Motivo**: Cada card mostra o motivo da prioridade e a temperatura do vínculo (🔥 Quente, 🧊 Observar).
4.  **Assuma a Tarefa**: Clique em **"Assumir"** para que o vínculo fique sob sua responsabilidade. Isso evita que dois mobilizadores falem com a mesma pessoa.
5.  **DM Manual**:
    - Clique em **Copiar DM** (ícone de cópia no card).
    - Clique em **Abrir Instagram** (ícone do Instagram).
    - Cole a mensagem, ajuste o nome da pessoa e envie.
6.  **Registre o Resultado**: No Quadro de Vínculos (`/abordagem`), selecione a resposta recebida e clique em **Confirmar Resposta**.

## 3. Gestão de Respostas e Encaminhamentos

Sempre que uma pessoa responder positivamente, você deve **encaminhá-la** para uma ação concreta na ficha da pessoa (`/pessoas/[id]`):

- **Evento de Campo**: Se ela quer participar presencialmente.
- **Voluntariado**: Se ela quer ajudar na organização.
- **Missão ÉLuta**: Se ela quer ajudar nas redes sociais.
- **Grupo de WhatsApp**: Se ela quer apenas acompanhar as notícias.

**Atenção**: Uma pessoa que respondeu bem mas não foi encaminhada ficará com o alerta 🟡 **FALTA ENCAMINHAMENTO**.

## 4. Quadro de Vínculos (Kanban)

O Quadro (`/abordagem`) é onde a mágica acontece. 
- **Filtros**: Use os filtros no topo para ver apenas suas tarefas ou tarefas "Órfãs" (sem dono).
- **Atraso**: Cards com borda vermelha e alerta 🔴 **CONTATO RECENTE** estão parados há mais de 48h. Priorize-os!
- **Balanceamento**: Coordenadores podem usar o botão **"Distribuir Carga"** para dividir tarefas órfãs entre a equipe ativa.

## 5. Respeito à Privacidade (Não Contato)

Se a pessoa pedir para não ser mais abordada:
1.  Selecione a resposta **"Não quer contato"**.
2.  O sistema aplicará um bloqueio visual 🔴 **NÃO ABORDAR** e ela sairá da lista de prioridades permanentemente.
3.  **Nunca** ignore esse pedido. O respeito é a base do vínculo.
