# Guia Operacional - Dia 0 do Piloto
## Preparação para o Início da Operação (7 Dias)

Este guia deve ser seguido pela coordenação antes de liberar o acesso total à equipe.

### 1. Checklist de Acesso e Configuração
- [ ] **Acesso dos Operadores**: Verificar se todos os convites do Supabase Auth foram aceitos.
- [ ] **Atribuição de Responsáveis**: Garantir que as tarefas iniciais em `/abordagem` tenham operadores definidos.
- [ ] **Distribuição de Carga**: Usar o botão "Distribuir Tarefas" para equilibrar a fila entre os operadores.
- [ ] **Templates de Mensagem**: Confirmar em `/mensagens` se os scripts iniciais (DM1, Boas-vindas) estão cadastrados e ativos.

### 2. Teste de Fluxo Ponta-a-Ponta
Realize um teste completo com um perfil de teste:
- [ ] **Copiar DM**: O botão de copiar funciona? (Testar na Lista Densa).
- [ ] **Abrir Instagram**: O link abre o perfil correto no Instagram?
- [ ] **Registrar Resposta**: Ao salvar uma resposta, a pessoa muda de coluna no Kanban?
- [ ] **Encaminhar**: Respostas que indicam interesse geram a sinalização de "Precisa Encaminhar"?
- [ ] **Não Abordar**: O sistema bloqueia ações em perfis marcados como "Não Abordar"?

### 3. Alinhamento de Rotina
- [ ] **Horário de Início**: Quando a equipe começa a disparar as DMs?
- [ ] **Fechamento do Dia**: Horário limite para registrar todas as respostas pendentes (Sugestão: 19h).
- [ ] **Canal de Suporte**: Onde os operadores reportam bugs ou dúvidas táticas (Ex: WhatsApp da Coordenação).

### 4. Monitoramento de Prontidão
No Dashboard, verifique o card **Dia 0 do Piloto**. Ele deve estar com status **PRONTO** (Verde).
