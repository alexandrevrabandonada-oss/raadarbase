# Guia de Treinamento do Operador - Radar de Base

Bem-vindo ao Radar de Base. Este guia orienta você sobre como utilizar o módulo de treinamento para se tornar um operador certificado na nossa plataforma.

## O que é o Modo Treinamento?
O Modo Treinamento é um ambiente seguro (/treinamento) onde você pode praticar todas as ações operacionais sem risco de alterar dados reais de cidadãos ou disparar eventos reais de auditoria.

## Estrutura do Treinamento

### 1. Cenários de Simulação
Você passará por 4 cenários críticos:
*   **Cenário 1 (Denúncia):** Foco no fluxo de cópia de DM e confirmação manual. Lembre-se: o Radar não envia DMs sozinho.
*   **Cenário 2 (Engajamento):** Aprenda a registrar quando alguém responde positivamente e como encaminhar para a Missão ÉLuta.
*   **Cenário 3 (Eventos):** Pratique o convite para eventos presenciais usando o Assistente de Encaminhamento.
*   **Cenário 4 (Privacidade):** Entenda como respeitar o desejo de "Não Abordar" de um cidadão.

### 2. Guardrails Éticos
Durante todo o treinamento (e na operação real), você deve seguir estes princípios:
*   **Não pedir votos:** O Radar é para escuta e mobilização, não para campanha direta de pedido de voto.
*   **DMs Manuais:** Toda mensagem deve ser colada e enviada manualmente no Instagram. Isso garante o tom humano.
*   **Respeito à Privacidade:** Se alguém pedir para não ser contatado, use o botão "Não Abordar" imediatamente.

## Como finalizar?
Após completar os cenários, você verá um Checklist. Marque todos os itens para confirmar que compreendeu as ferramentas e as regras éticas.

## Próximos Passos
Após concluir o treino, você poderá acessar o seu Dashboard e começar a processar sua fila real de tarefas.
