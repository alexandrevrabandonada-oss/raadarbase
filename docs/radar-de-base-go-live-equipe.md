# Guia de Go-Live: Radar de Base (Equipe Real)

Este documento orienta a equipe na transição para o uso do Radar de Base com dados reais. O foco é a **relação humana**, a **privacidade** e o **cuidado territorial**.

## 1. Como Acessar
- **URL**: [URL_DE_PRODUCAO] (Siga as orientações do administrador).
- **Login**: Utilize seu e-mail institucional/convidado.
- **Ambiente**: Certifique-se de que o aviso "Modo Demonstração" **NÃO** está visível. Você está lidando com dados reais.

## 2. Rotina Diária (Ciclo de 7 Passos)
Siga esta rotina todos os dias para manter a base saudável:
1.  **Ver 10 pessoas**: Acesse a aba **Pessoas** e veja a lista de abordagens prioritárias calculadas pelo sistema.
2.  **Assumir Responsável**: Se você vai falar com alguém, clique em **Assumir Vínculo**. Isso evita que duas pessoas falem com o mesmo contato.
3.  **Abordagem Manual**: Use o botão **Abrir Instagram**. Não use automações.
4.  **Mensagem Humana**: O sistema sugere uma mensagem. **Adapte-a**. Use o nome da pessoa e mencione o contexto do comentário dela.
5.  **Registrar Resposta**: Após enviar e receber retorno, volte ao Radar e registre: "Respondeu bem", "Pediu informações", etc.
6.  **Encaminhar**: Transforme a conversa em ação. Encaminhe para:
    - **Ação de Campo**: Se a pessoa quer participar presencialmente.
    - **Missão ÉLuta**: Se ela quer ajudar digitalmente.
    - **Voluntariado**: Se ela quer entrar para a equipe.
7.  **Fechar Pendências**: Mova os cards no Kanban de **Abordagem** até a coluna de conclusão ou encaminhamento.

## 3. O que NUNCA fazer (Linhas Vermelhas)
- ❌ **Nunca peça voto**: Estamos em período de pré-campanha. O foco é escuta e mobilização temática.
- ❌ **Nunca use bots ou disparadores em massa**: O Radar é uma ferramenta de apoio à relação humana, não um spammer.
- ❌ **Nunca ignore um pedido de privacidade**: Se a pessoa pedir para não ser contatada, use o botão **Marcar como não abordar** imediatamente.
- ❌ **Nunca registre dados sensíveis**: Não anote religião, orientação sexual ou dados de saúde nas notas internas.

## 4. Divisão de Responsabilidades
- **Admin**: Gerencia usuários, importa lotes de dados e revisa incidentes.
- **Operador (Você)**: Faz a abordagem, cuida do vínculo e realiza encaminhamentos.
- **Comunicação**: Revisa os templates de mensagens e temas detectados.

## 5. Como Reportar Problemas
Se encontrar um bug ou erro de dados:
- Registre o ID da pessoa (UUID na URL).
- Descreva o que aconteceu.
- Informe ao Administrador via canal oficial de suporte.

## 6. Primeira Carga Operacional
Para iniciar o piloto com dados reais, o administrador realizou a seguinte carga:
- **Seed de Templates**: Modelos de mensagens de pré-campanha (Saúde, Educação, Denúncia) já estão disponíveis na aba **Mensagens**.
- **Criação de Tarefas Iniciais**: 50 pessoas prioritárias foram selecionadas automaticamente e enviadas para a coluna **Para abordar** no Kanban de **Abordagem**.
- **Ação**: Abra o Kanban, escolha um card sem responsável, clique em **Assumir** e inicie o piloto.
